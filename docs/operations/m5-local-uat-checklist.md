## Entry conditions

- For local preparation, use only the built-in synthetic demo or the bundled synthetic corpus. Use a new temporary SQLite path outside the repository. Do not copy production data or real CVs into the workspace.
- Leave OCR credentials, endpoint, and allowlist unset. Keep the service on `127.0.0.1`; do not expose it to a network.
- Capture the build/pipeline version, browser and OS, viewport, and test date. Record only synthetic sample IDs and UI outcomes; do not paste CV text or personal data into issue trackers.
- Formal business UAT requires completed M0 scope and data authority, M2 evaluation targets, M3 identity/access and privacy/security controls, and M4 staging/operations readiness. The current prototype lacks SSO/RBAC and approved production controls, so do not treat a local walkthrough as formal UAT.

Use the local startup and stop steps in the [M4 runbook draft](m4-local-runbook-draft.md). The preflight command runs a broader smoke suite; use it only when a scheduled phase checkpoint or release review calls for that suite.

Keyboard retest confirmed visible focus on both selects, the note field, buttons, and intake controls.
- **M5-DEF-03 · P2 · Resolved:** the reviewer note relied on placeholder text and had no programmatic label. The generated textarea now receives a candidate-specific ID and an associated visually-hidden label; the rendered accessibility tree and a label-based locator both expose the expected name.

For each failure, capture the scenario ID, synthetic sample ID if relevant, expected and observed behavior, severity, browser/OS, viewport, and a screenshot with no real personal data. Do not attach SQLite files, OCR payloads, full CV text, or contact details to the report.

Use this simple severity scale:

- **P0:** data exposure, unauthorized access, destructive loss, or incorrect automated employment outcome. Stop the test and escalate through the approved security/privacy process.
- **P1:** core workflow blocked, evidence attached to the wrong criterion/source, privacy safeguard bypassed, or keyboard/screen-reader operation prevented.
- **P2:** important content or action is difficult to find/use, responsive layout breaks, or error recovery is unclear.
- **P3:** cosmetic or low-impact issue with a clear workaround.
