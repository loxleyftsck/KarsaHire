Urut menurut cakupan bukti teks

◈ Gunakan CV sintetis saja. Unggah file manual dinonaktifkan secara default; demo memakai fixture sintetis lokal. Berkas sumber tidak disimpan, tetapi profil, kutipan bukti, dan review tersimpan di database lokal. Dataset uji memakai teks sintetis tanpa OCR. Jika OCR diaktifkan, gambar halaman dikirim ke API yang dikonfigurasi (maksimal 6 permintaan per menit). Persentase menunjukkan kecocokan frasa dan token, bukan penilaian kelayakan.
