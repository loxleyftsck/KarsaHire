# Synthetic CV test batch (32)

Source: sukhrobnurali/resume-parsing-vision on Hugging Face, test split (first 32 records).
Source revision: 3c254be39d45f69c6e20bfb325b4e6ccb3b5e393.
License: CC BY 4.0. Attribute the dataset to its Hugging Face source when redistributing.

The source dataset card states that all resumes and identity details are synthetic and contain no real personal data. These files are for parser/OCR and ranking experiments only; do not treat them as real applicants.

Each sample folder contains source page images, a resume_text.txt reference, expected.json ground truth, and metadata.json. A combined PDF is created from the page images for direct upload into the local prototype.
